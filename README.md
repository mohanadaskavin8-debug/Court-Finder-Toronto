# Court Finder

**Court Finder** is a Toronto court finder that helps people find basketball courts and other recreational locations around the city.

The goal was to make finding a court simple: search for a location, browse nearby courts, and quickly see useful information without having to look through multiple websites.

## Features

* Search for courts and recreational locations
* Browse courts by location
* View courts on an interactive map
* Search for buildings, fields, facilities, and other locations
* Find events connected to locations
* Filter event results based on your search
* View location details
* Responsive design for desktop and mobile

## How it works

The main experience is built around search and location discovery.

A user can search for a court, building, field, facility, or other location. The application filters the available results and displays relevant locations and events.

The map provides another way to explore the results geographically.

## Why I built it

I wanted to make it easier to find places to play around Toronto.

There are a lot of courts and recreational facilities, but the information is often spread across different websites and maps. 6ixCourts brings the search experience into one place.
